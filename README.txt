DIGISAFE - VERSI BARU

Isi ZIP:
1. index.html - seluruh website (HTML, CSS, dan JavaScript sudah dalam satu file).
2. README.txt - petunjuk singkat.

Cara menjalankan:
- Ekstrak ZIP.
- Buka folder di Visual Studio Code.
- Buka index.html dengan browser atau Live Server.

Fitur:
- Navigasi responsif.
- Masuk demo.
- Cek Informasi berbasis kata kunci.
- Pindai Risiko kebiasaan digital.
- Kuis 5 soal, skor, pembahasan, dan ulangi.
- Bantuan dan Privasi.

Catatan:
Ini prototipe front-end. Login bukan autentikasi sungguhan. Pemeriksa pesan tidak bisa memastikan penipuan secara pasti dan website tidak memindai perangkat.
